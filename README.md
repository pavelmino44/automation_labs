# Automation Labs

Лабораторные работы по предмету **«Программное обеспечение мехатронных и робототехнических систем»**.

Репозиторий содержит четыре проекта, разработанных в среде **B&R Automation Studio** (версии 4 и 6).

## 📚 Содержание

| № | Проект | Описание |
|---|--------|----------|
| 1 | [Lab_1](./Lab_1) | Лабораторная работа №1 |
| 2 | [Lab_2](./Lab_2) | Лабораторная работа №2 |
| 3 | [Lab_3](./Lab_3) | Лабораторная работа №3 |
| 4 | [Lab_4](./Lab_4) | Лабораторная работа №4 |

---

## 🛠️ Требования

- **B&R Automation Studio 4.x или 6.x**
- **Git** (для клонирования репозитория)
- При необходимости — **Automation Runtime**, **mappTechnology**, **Safety** (в зависимости от содержимого конкретной лабораторной)
